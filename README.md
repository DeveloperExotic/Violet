# Violet

> **A Chrome browser that removes bullshit and adds useful stuff.**

Violet is a Chromium-based browser focused on **performance, privacy, customization, and user control**.

![](https://raw.githubusercontent.com/DeveloperExotic/Violet/refs/heads/main/violet.png)

## Features

- **Performance**:&nbsp;&nbsp;&nbsp;Latest Chromium with Thorium and Violet optimizations
- **Violet Addons**:&nbsp;&nbsp;&nbsp;Custom settings at `violet://settings/addons`
- **Privacy Controls**:&nbsp;&nbsp;&nbsp;Disable telemetry and unwanted Google services
- **Built-in Ad Blocker**:&nbsp;&nbsp;&nbsp;Blocks ads, trackers, annoyances, popups, and malicious domains
- **Userscripts**:&nbsp;&nbsp;&nbsp;Built-in userscript management and website customization
- **Flash Support**:&nbsp;&nbsp;&nbsp;Legacy Flash content through a modern, secure runtime
- **Customization**:&nbsp;&nbsp;&nbsp;Custom accent colors, themes, UI options, and more
- **Vertical Tabs**:&nbsp;&nbsp;&nbsp;Optional Firefox-like vertical tab layout
- **Tab Groups**:&nbsp;&nbsp;&nbsp;Group, pin, and organize tabs
- **Chrome Extensions**:&nbsp;&nbsp;&nbsp;Chrome extension compatibility
> **Keep what people love. Remove what they don't. Add what they need.**

## Platform Support

Violet supports **desktop platforms**, including:

- Windows
- macOS
- Linux
- ChromeOS
